### 0.3 Binding rule and action policies

The manuscript uses the draft's text word for word. A word is changed only where the Springer format strictly needs it, and every such change is wrapped in `\chg{new}` / `\del{removed draft text}` in the marked master.

| Code | Meaning |
|---|---|
| **MECH** | Mechanical conversion with no highlight: citation syntax (`\cite`); cross-reference numbering (Roman to Arabic through `\ref`); LaTeX escaping and diacritics; heading and list numbering markers; typographic quotes and dashes; Unicode symbols to LaTeX equivalents; float placement. |
| **LAYOUT** | Class options, package choice, figure width, table column specs and font size inside tables. None of these touch wording, so no highlight. |
| **CHG** | A minimal wording change is allowed and must be wrapped in `\chg{}`/`\del{}`. Put the justifying G-ID next to each one as a same-line comment (`% [G30]`). Comments are harmless in the clean file. |
| **PRESERVE+FLAG** | Keep the draft text unchanged. Record the issue in the review report's *Flags for authors* list, not in the .tex. Change it only if the authors instruct it, and then as CHG. |
| **AUTHOR-INPUT** | New content that only the authors can supply (facts or statements). In the marked file, insert it as `\chg{AUTHOR INPUT REQUIRED: ...}`. Submission is blocked until the authors fill it: G11 fails while any placeholder remains in the clean file. Never invent facts. |
| **FIX** | A separate category, outside Springer formatting: `\fix{new}` / `\fixdel{removed}` mark a *factual correction against the implementation* (added to `tools/make_clean.py` and `fidelity_check.py` on 15 Oct 2026). These are never used for format compliance. Each needs evidence (a repo file path, commit or measurement) in a same-line comment, `% [FIX: path or commit]`, and is audited in G60/G61. |

Categories: **M** = Mandatory-general (Springer-wide or template-technical, non-optional). **J** = Journal-dependent or advisory ("as a guide", "check your journal"). **P** = Procedure required by the binding rule.

When to remove `\del{...}` text: a `\del` or `\fixdel` used for cross-reference text should contain the `\ref` form (for example `\del{Table~\ref{tab7}}`), not a literal Roman numeral. Otherwise `fidelity_check.py` reports a false difference, because it converts only the draft side from Roman to Arabic.

## A. Template, class and compilation

### G01: Use the Springer Nature LaTeX template (sn-jnl v3.1, Dec 2024), unmodified
- **Rule:** Use the Springer Nature LaTeX authoring template. Keep `sn-jnl.cls` in the same directory as the manuscript, and do not edit it.
- **Source:** S1 *Journal Authors: Preparing Your Research*; S3 §2, §10; S2 l.1.
- **Category:** M
- **Verify:** `cmp paper/springer-nature/sn-jnl.cls paper/sn-article-template/sn-jnl.cls && cmp paper/springer-nature/sn-mathphys-num.bst paper/sn-article-template/bst/sn-mathphys-num.bst`. Both must be silent (`guideline_checks.py` G01).
- **Action:** MECH. If either file differs, restore it from the template.

### G02: Class options: `\documentclass[pdflatex,sn-mathphys-num]{sn-jnl}`
- **Rule:** Snapp requires pdflatex, and the `pdflatex` option is the template default. Keep single-column (the default; `iicol` only if the journal requires it). The template asks for `[referee]` (double spacing) for peer review and offers `[lineno]`; both are journal-dependent and change layout only.
- **Source:** S1 *Submitting Your Research* ("must compile using pdflatex"; eJP: "use the pdflatex option in the preamble"); S2 l.20-33; S3 §2.1.
- **Category:** M for `pdflatex` and the reference-style option. J for `referee`/`lineno`/`iicol`.
- **Verify:** `grep -n '^\\documentclass' paper/springer-nature/forgeflow-springer.tex` must print exactly `\documentclass[pdflatex,sn-mathphys-num]{sn-jnl}` (any extra option is WARNed by G02).
- **Action:** LAYOUT. Add `referee`/`lineno` only at submission time, and only if the chosen journal asks for them.

### G03: Reference style: sn-mathphys-num (numbered), with justification
- **Rule:** Pick the bibliography style that fits the journal. The template defaults to sn-mathphys-num (S2 l.33), and the target journal's style takes precedence (S3 §8.3).
- **Justification:**
  1. The draft uses IEEE numbered citations in square brackets, numbered by first citation ([1]-[32]).
  2. sn-mathphys-num gives `[n]` brackets through natbib `numbers,sort&compress`. Its .bst default option `unsort` keeps citation order. I tested this with 12 entries in reverse-alphabetical order: they kept citation order, so the draft's numbering [1]-[32] is reproduced exactly. It renders `[3, 4]` and compresses ranges to `[5-7]`, and it supports `doi`, `url`, `urldate` ("Accessed ..."), `eprint` and `note` (S11).
  3. The draft uses citations as nouns, for example: "The critical negative result is [11]" (§II-C); "mentioned in [22]" (§II-D); "named in [22]" (P3); "the lesson of [13]" (P2); "the mechanism that [11] recommends" (§V-A); "defined in [21]" (§V-D); "The motivation given in [6]" (§VI-A); "reported ... in [4]", "enumerated in [24]" (§VII). An author-year style would force rewording, which the binding rule forbids.
  4. Alternatives I rejected:
     - sn-vancouver-num: numbered, but uses medical-style names and abbreviations.
     - sn-aps: physics conventions.
     - sn-basic and sn-chicago: author-year unless `Numbered` is added.
     - sn-nature: Nature Portfolio only.
- **Source:** S2 l.28-39; S3 §7.9, §8.3; S5 *References* ("identified by numbers in square brackets"); S11.
- **Category:** J. Some Springer journals require author-year, for example S4: "Cite references in the text by name and year in parentheses".
- **Verify:** Run the G38 check. **Inspect** the PDF: citations print as `[n]`.
- **Action:** LAYOUT. If the chosen journal mandates author-year, do not switch silently: PRESERVE+FLAG and let the authors decide, because each noun-citation would need a wording decision.

### G06: No custom fonts

### G07: Minimal, standard packages; nothing the class already loads
- **Rule:** Avoid non-standard packages and macros ("frequent causes of error"). Add packages only where necessary. sn-jnl already loads hyperref, natbib, geometry, amsthm and the bibliography style.
- **Source:** S3 §1, §2; S2 l.41-57; class source (S11).
- **Category:** M
- **Verify:**
  - `grep -n '\\usepackage' paper/springer-nature/forgeflow-springer.tex`. Allowed: the template list (graphicx, multirow, amsmath, amssymb, amsfonts, amsthm, mathrsfs, appendix, xcolor, textcomp, manyfoot, booktabs, algorithm, algorithmicx, algpseudocode, listings). Any extra package needs a one-line justification (G07 WARN).

  - Do not load hyperref, geometry, natbib, subfig, subcaption or titlesec.
  - `ulem` and the `\chg`/`\del` definitions belong only between `%%% CHANGE-MARKUP-BEGIN/END`, so `make_clean.py` removes them.
- **Action:** LAYOUT.

### G08: ASCII-only sources; diacritics and special characters as TeX code
- **Rule:** Convert special characters, including diacritics, to TeX code (`ä` to `\"a`; the bracketed forms `{\"a}` are fine). The same applies to the .bib file, because unconverted characters are a listed cause of missing references.
- **Source:** S1 *Preparing Your Research*, *FAQs: Special Characters*, *FAQs: Missing References*.
- **Category:** M
- **Verify:**
  - `grep -nP '[^\x00-\x7F]' paper/springer-nature/forgeflow-springer-marked.tex paper/springer-nature/forgeflow-springer.tex paper/springer-nature/*.bib` must print nothing.
  - Fallback if `-P` is unavailable: `perl -ne 'print "$ARGV:$.: $_" if /[^\x00-\x7F]/; close ARGV if eof' <files>`.
  - The .log must contain no "Missing character" lines (G08).
  - Use the mapping in Appendix 1.
- **Action:** MECH.

### G09: Text-mode characters that misprint in pdflatex's default OT1 encoding
- **Rule:** This is a consequence of G06/G08. sn-jnl uses OT1 and does not load T1 fontenc. In text mode `<` prints as ¡, `>` as ¿ and `|` as an em-dash (verified by compile). `{ } _ % & # $ ~ ^ \` must be escaped.
- **Source:** S11 (compile test); S3 §3.2.
- **Category:** M
- **Verify:**
  - `grep -nE '[<>|]' paper/springer-nature/forgeflow-springer.tex`: every hit must be inside math, a tabular preamble or `\textless`/`\textgreater`/`\textbar`.
  - `pdftotext paper/springer-nature/forgeflow-springer.pdf - | grep -n '[¡¿]'` must print nothing (G09).
- **Action:** MECH. Draft hits: "refine | proceed | skip" (§III), "admin panel > environment > default" (§VII), "p < 0.001" (abstract, Table VII), `{...}` braces in event/record shapes, and the underscores in all identifiers (`criterion_id`, `awaiting_user`, `forgeflow_meta`, `stall_threshold`, `max_iterations`, `infra_plan`, `cost_inr`, `wall_clock_s`, `failing_by_iteration[]`, ...).

### G10: Semantic markup only; no manual spacing; no coloured text in the clean file
- **Rule:**
  - Fine-tuning commands (`\break`, `\pagebreak`, `\vspace`, `\bigskip`, `\clearpage`, ...) "are not encouraged; please use semantic mark-up". Do not use manual skips to align equations.
  - Coloured font is not supported in the full-text XML.
- **Source:** S3 §2.1, §7.2; S2 l.148.
- **Category:** M (the clean file is what production converts).
- **Verify:** Run `grep -nE '\\(vspace|vskip|hspace|bigskip|medskip|smallskip|clearpage|newpage|pagebreak|linebreak|enlargethispage|color|textcolor|colorbox)\b' paper/springer-nature/forgeflow-springer.tex`. Each hit needs a justification (G10 WARN).
- **Action:** LAYOUT. Colour is allowed only in the marked review copy, through `\chg`/`\del`.

### G11: The clean file is a faithful, markup-free derivative of the master
- **Rule:**
  - Springer receives plain sn-jnl LaTeX: no `\chg`/`\del`/`\fix`/`\fixdel`, no markup block, no placeholders, no reviewer notes.
  - The clean file must only ever be produced by `tools/make_clean.py`, which `build.sh` runs.
- **Source:** Binding rule; S2 l.148 (no colour).
- **Category:** P
- **Verify:** `grep -nE '\\(chg|del|fix|fixdel)\{|CHANGE-MARKUP|AUTHOR INPUT|TODO|FIXME|XXX' paper/springer-nature/forgeflow-springer.tex` must print nothing (G11).

- **Rule:** `\title[<short>]{<full>}`: the full title is mandatory and the short form is optional. Springer asks for a concise, informative title.
